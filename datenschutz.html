Datenschutz.

Informationen zu den verwendeten Daten, ihrer Verarbeitung und deinen Zugriffsmöglichkeiten.

Textstand: 17. September 2026

Projekt und Kontakt

Das MagicMirror Dashboard ist ein privat genutztes Raspberry-Pi-Projekt von Tim (GitHub: Rettungsfrequenz). Kontakt: tim.boecker2006@gmail.com

Zugriff auf Google Tasks

Nach ausdrücklicher Freigabe durch den Kontoinhaber liest die Anwendung Aufgabenlisten und Aufgaben über die Google Tasks API. Dazu können Listennamen, Aufgabentitel, Notizen, Fälligkeit und Erledigungsstatus gehören.

Die Daten werden zur Anzeige persönlicher Aufgaben auf dem eigenen Dashboard verwendet. Die Berechtigung tasks.readonly erlaubt ausschließlich lesenden Zugriff. Aufgaben werden durch das Dashboard weder geändert noch gelöscht.

Verarbeitung und Speicherung

Die Aufgaben werden von Google an den Raspberry Pi übertragen und dort für die Dashboard-Anzeige verarbeitet. Die ursprünglichen Aufgaben bleiben im Google-Konto. OAuth-Zugangstoken werden auf dem Raspberry Pi gespeichert, damit die Anwendung Aufgaben erneut abrufen kann.

Aufgaben und Zugangstoken werden nicht auf dieser Informationswebsite oder im öffentlichen GitHub-Repository veröffentlicht. Google-Nutzerdaten werden nicht verkauft, für Werbung verwendet oder zum Training von KI-Modellen genutzt.

Zugriff widerrufen und Daten entfernen

Der Kontoinhaber kann die Zugriffsberechtigung jederzeit unter Verbindungen im Google-Konto entfernen. Dadurch wird der weitere autorisierte Abruf beendet. Lokal gespeicherte Zugangstoken können auf dem Raspberry Pi gelöscht werden. Zum Entfernen der laufenden Aufgabenanzeige wird das Dashboard beendet und das Anzeigefenster geschlossen. Die ursprünglichen Aufgaben lassen sich in Google Tasks löschen.

Hosting dieser Informationswebsite

Diese Website wird von GitHub Pages bereitgestellt. GitHub protokolliert und speichert die IP-Adressen von Besuchern zu Sicherheitszwecken. Diese Website bindet selbst keine Analyse- oder Werbedienste ein. Weitere Informationen stehen in der Datenschutzerklärung von GitHub .
